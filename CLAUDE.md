# Project Instructions

## Project
A premium multi-branch hotel website built using React (frontend) and Django REST Framework (backend).

## Development Rules
- Always inspect existing code before making changes.
- Never rewrite or modify unrelated files.
- Work only on the requested feature.
- Use JavaScript JSX, never TypeScript.
- Use Tailwind CSS for styling.
- Prefer reusable components.
- Write clean, maintainable, production-friendly code.
- Do not install packages without asking first.
- Do not create unnecessary files or components.
- Maintain the existing folder structure and coding conventions.
- Do not use hardcoded dummy data when backend integration is requested.
- Make the UI fully responsive.
- Avoid generic template-like designs.

## Design Guidelines
- Primary colors: Orange, warm white and subtle dark shades.
- Premium restaurant/hospitality aesthetic.
- Smooth transitions and meaningful hover effects.
- Consistent spacing, typography and visual hierarchy.
- Prioritize user experience and performance.

## Workflow
- Work step by step.
- Complete only the requested task.
- Explain files changed and important implementation decisions.
- Never move to the next feature without being asked.



## Execution & Testing Rules
- Do NOT run `npm run dev`, `npm start` or any command that starts the project.
- Do NOT run `npm run build` or production builds.
- Do NOT run tests or lengthy verification commands unless explicitly requested.
- I will run the project and verify the changes manually.
- You should inspect the code and make the requested changes without starting the application.
- Never claim that something was tested or verified if you did not actually test it.
